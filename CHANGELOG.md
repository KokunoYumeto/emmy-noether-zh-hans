# Changelog

## 1.0.0 — 2026-08-14

- First independent DOI release of the complete PRC-oriented Simplified-Chinese Emmy Noether corpus.
- Adds a DOI/source/coverage cover to the unchanged 424-page frozen r10b body.
- Publishes editable sources, exact source/coverage evidence, build and render receipts, and SHA-256 manifests.
- Before the immutable Zenodo publication, the provisional GitHub source/evidence
  assets were replaced to remove machine-local credential-path metadata, exclude
  generated Python bytecode, make the build portable, and state mixed rights and
  target-span coverage exactly. The reader PDF itself was unchanged.
