# Decision provenance

The current complete public decision-provenance bundle is released with version 1.0.3 at [10.5281/zenodo.22177336](https://doi.org/10.5281/zenodo.22177336) as `05_NOETHER_zh-Hans_PROVENANCE.zip` (731,079 bytes; SHA-256 `45BBC7055D6B71C118F3424DF2208322C786FDC190EB5DD85176B53D2513480E`).

It contains the producer and independent-checker decision logs through producer decision `CJK-NOT-D041`, checker decision `ZHCHK-D132`, and checker state event `STATE-20260830-044`, together with the frozen r10b release, exact freeze and acceptance receipts, manifests, and publication/backend verification evidence. An internal manifest binds every bundled copy to its path, byte count, SHA-256 identity, and local source preimage. Version 1.0.3 inherited release files 00, 01, 02, and 04 byte-for-byte and replaced only the checksum file 03 and cumulative provenance file 05; it made no corpus change.

For privacy, textual copies replace the local account holder's first name with `[USER]`. The unredacted source-preimage hashes are retained, but credentials, caches, render dumps, and other disposable machine-local material are excluded. This privacy transform does not alter the Chinese corpus, mathematics, German authority, or release PDFs.
